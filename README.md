# 🎧 Spotify Clone

A **premium Spotify Web Player clone** built with **HTML5, CSS3, CSS Grid, and Vanilla JavaScript**, featuring a modern **glassmorphism interface**, immersive animations, and a fully browser-powered music experience.

Designed to deliver the look and feel of Spotify with a futuristic aesthetic, responsive layout, and smooth interactions—all without using any frameworks.

---

## ✨ Features

### 🎵 Generative Audio Engine
- Procedurally generated lo-fi ambient music
- Built entirely using the **Web Audio API**
- Dynamic chord progressions and relaxing beats
- Infinite playback with **no audio files required**
- Fully offline experience


### 📐 Responsive Layout
- CSS Grid powered architecture
- Independent scrolling sidebar
- Responsive content area
- Sticky bottom music player
- Desktop, tablet, and mobile support

## 🛠 Tech Stack

- HTML5
- CSS3
- CSS Grid
- Flexbox
- Vanilla JavaScript (ES6+)
- Web Audio API
- HTML5 Canvas API
