# Spotify Clone

A premium, glassmorphic Spotify Web Player clone built using CSS Grid, HTML5, and vanilla JavaScript. 

## Features
- **Generative Audio Synth**: Plays looping, chill lo-fi ambient chord progressions and beats entirely offline using the browser's native **Web Audio API**.
- **Canvas Visualizer**: Features a real-time, responsive 3-layer wave visualizer that animates smoothly.
- **Glassmorphism**: Elegant transparent cards with micro-animations, green glow shadows, and scaling translations.
- **Independent Layout Scrollbars**: A grid-based viewport where the sidebar, main window, and bottom player bar sit perfectly without overlaps.
