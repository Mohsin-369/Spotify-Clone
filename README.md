# 🎧 Spotify Clone

A **premium Spotify Web Player clone** built with **HTML5, CSS3, CSS Grid, and Vanilla JavaScript**, featuring a modern **glassmorphism interface**, immersive animations, and a fully browser-powered music experience.

Designed to deliver the look and feel of Spotify with a futuristic aesthetic, responsive layout, and smooth interactions—all without using any frameworks.

---

## ✨ Features

### 🎵 Generative Audio Engine
- Procedurally generated lo-fi ambient music
- Built entirely using the **Web Audio API**
- Dynamic chord progressions and relaxing beats
- Infinite playback with **no audio files required**
- Fully offline experience

### 🌊 Real-Time Audio Visualizer
- Multi-layer waveform visualizer
- Built using the **HTML5 Canvas API**
- Smooth 60 FPS animations
- Audio-reactive wave effects
- Responsive across all screen sizes

### 💎 Premium Glassmorphism UI
- Frosted glass cards
- Blur and transparency effects
- Spotify-inspired dark theme
- Neon green accent glow
- Soft shadows and depth
- Modern rounded interface

### ✨ Smooth Animations
- Hover micro-interactions
- Card lift animations
- Button scaling effects
- Floating UI elements
- Seamless transitions
- Animated navigation

### 📐 Responsive Layout
- CSS Grid powered architecture
- Independent scrolling sidebar
- Responsive content area
- Sticky bottom music player
- Desktop, tablet, and mobile support

### 🎚 Interactive Player
- Play / Pause controls
- Progress bar
- Volume slider
- Shuffle & Repeat buttons
- Responsive playback controls

### ⚡ Optimized Performance
- Built with pure Vanilla JavaScript
- Lightweight and fast
- No external libraries
- Smooth rendering
- Offline compatible

## 🚀 Getting Started

```bash

# Navigate to the project
cd spotify-clone

# Open index.html
```

Or simply open **`index.html`** in your browser.
